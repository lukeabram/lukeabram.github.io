NVIDIA, Multi-Instance GPU (MIG) technology page

NVIDIA’s overview of Multi-Instance GPU, which splits one GPU into as many as seven isolated instances, each with its own memory, cache, and compute. It is useful for the “other noteworthy features” part of the report, and its specifications table gives the memory per instance on HGX B200.

Read at NVIDIA.

The page has no date. The footer reads “Copyright © 2026”. Product pages change without notice, so record the date you read it. Used in section D.

Where to look

  • “How the Technology Works”, “MIG in NVIDIA Blackwell and Hopper GPUs”. Covers multi-tenant configurations, confidential computing for each instance, and a dedicated video decoder for each instance.
  • “MIG Specifications” table. Gives memory per instance at 7, 4, 2, and 1 instances for GB300 NVL72, HGX B300, GB200 NVL72, and HGX B200. The B200 values are “up to” 21, 45, 90, and 180 GB.
  • “Built for IT and DevOps”. Links to deployment documentation for containers, Kubernetes, and virtual machines.

We could not read the specifications table verbatim with an automated fetch, so check the figures in a browser before citing them. The 180 GB single-instance figure agrees with the Tuning Guide and the HGX reference architecture.
