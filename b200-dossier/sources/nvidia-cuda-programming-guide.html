CUDA Programming Guide

The CUDA C++ view of the same features that PTX defines. It is easier to read than the PTX manual and is the right place to start for thread block clusters, distributed shared memory, and asynchronous barriers.

Read at NVIDIA.

The guide was reorganized in 2025; the old cuda-c-programming-guide URL now redirects here. Section numbers refer to the reorganized edition. Used in sections A, B.

Where to look

  • Programming Model, §1.2. The thread, warp, block, cluster, and grid hierarchy.
  • Asynchronous Barriers, §4.11. The CUDA-level interface to mbarrier.
  • Asynchronous Data Copies, §4.13. TMA bulk copies from C++.
  • Cluster Launch Control, §4.14. Work stealing across clusters, new with Blackwell.
  • Compute Capabilities, §5.1. What sm_100 and the architecture-specific sm_100a target mean.
